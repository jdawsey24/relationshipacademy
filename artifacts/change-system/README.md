# RLC Change System Architecture

`rlc-change-system-architecture-v1.md` — Draft v1 of the governing change architecture that translates a
presenting relational problem (Experience Cluster) into an appropriate developmental change pathway, using
ONLY existing canonical RLC constructs.

**Type:** operational/application architecture, not new theory. Adds no competencies/barriers/clusters/
tasks/domains/phases. Introduces two operational instruments (Functional Interference Gate; Mechanism-vs-
Format distinction) + one analysis-time scaffold (Problem Expression, non-canonical).

**Core pipeline:** Presenting Experience -> Problem Expression -> Developmental Context -> [Functional
Interference Gate] -> Interference Analysis (Competency/Barrier/Combined/Neither) -> Change Target ->
Change Mechanism -> Intervention (mechanism x format x safety x intensity) -> Developmental Application ->
Outcome/Maintenance, with a Measurement spine.

Includes the Cluster 1 stress test (all 8 problem expressions), the architecture quality test, unresolved
questions, and a decision log. STOPS for human review; no interventions created; 333 templates untouched.

Depends on: ../intervention-coverage/ (the two prior analyses).
