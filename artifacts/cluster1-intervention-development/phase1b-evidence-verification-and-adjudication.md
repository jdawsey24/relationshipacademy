# Cluster 1 — Difficulty Feeling Chosen · Intervention Development Phase 1B
## Evidence Verification & Technique Adjudication

**Status:** PHASE 1B artifact for human review. **No interventions authored.** Verifies the Phase-1 candidate
pool against primary scholarly sources, applies the approved human adjudications, and adjudicates each
mechanism/technique. Governing: **RLC Intervention Development Standard v1.0 (FROZEN)** + Change System Final
v1 (rev v1.1). Context (fixed): **Exploration → Discernment.** Candidate pool **frozen** — no new mechanisms
added (none of the §1 replacement conditions were met).

**Verification method:** claims re-checked via publisher/authoritative sources (SAGE, APA, Springer,
ScienceDirect, Tandfonline, NCBI). Discovery aids (ResearchGate/Semantic Scholar) were **not** used as the
evidentiary authority. Effect sizes/Ns are reported as found and still carry a **final page-proof verification
flag** before Phase-2 authoring (DOIs listed where confirmed).

### Headline changes from Phase 1 (verification-driven)
1. **Self-distancing (M1)** demonstrably improves **wise *reasoning* about romantic *scenarios*** — **not**
   behavior, not actual dating-fit decisions, no transfer/follow-up. → advances, but the Discernment payoff is
   an explicit **RLC bridge (Link 7 untested)**.
2. **Consider-the-opposite (technique) DOWNGRADED** — real-world/pre-registered evidence is weak/mixed. The
   *mechanism* (evidence discrimination) survives; the *specific technique* moves to **Hold/supporting**.
3. **"Behavioural experiments outperform verbal methods" DOWNGRADED** — the actual RCT found both effective,
   **no BE superiority**. BE advances as *a* method, safety-gated, not as "the strongest."
4. **Sunk-cost *education* DOWNGRADED** — the effect exists in relationship decisions, but awareness alone is
   insufficient and there is **no evidence** correcting it improves real relationship decisions. Reframed to a
   **prospective forward-value criterion** (pairs with implementation intentions).
5. **Attribution re-scoping (M3) CONDITIONAL** — real intervention evidence exists but in **achievement**
   contexts and toward **controllability**; RLC needs only the **global→specific** dimension. Controllability
   framing is a **failure mode** (it would feed PE-3 self-editing).
6. **Implementation intentions confirmed strongest**, with a decisive boundary: **volitional, not
   motivational** — the if-then is only as good as its **pre-established decision criterion** → evidence
   discrimination must precede/pair with it.
7. **Self-affirmation/self-compassion** confirmed **buffer-only, modest** (self-affirmation d≈0.41); **no**
   evidence they improve relational reasoning/decisions.

# DELIVERABLE 8 — Failure Mode / Misuse Matrix
| Technique | Key failure modes (→ guardrail later) |
|---|---|
| Distanced reflection | **invalidating** ("just detach"); depersonalization; used to avoid real feeling |
| Implementation intentions | **rigid/compulsive** rule-following; criterion set from anxiety not evidence; scorekeeping |
| Evidence-weighing | **false equivalence** ("every read has an equal opposite"); **hypervigilant** monitoring; erasing real evidence of mistreatment |
| Behavioural experiment | **indiscriminate vulnerability**; running it in an **unsafe** relationship; reading one outcome as a verdict |
| Forward-value prompt | **cold/transactional**; pressure to leave; ignoring genuine repair |
| Attribution re-scoping | **controllability trap** → self-editing ("be more chooseable"); minimizing real patterns |
| Self-affirmation/compassion | **falsely reassuring**; used to bypass accurate negative evidence; complacency |
| (PE-6 any) | **teaching optimism over evidence**; challenging *accurate* expectancy |
| (PE-7) | **labeling normal rest as avoidance**; pushing re-entry ("get back on the apps") |

# DELIVERABLE 13 — Evidence Gaps Remaining After Verification

  attainment, belief change, achievement) to **real dating-fit evidence-reading and decisions** is untested.

  inference.
- **PE-6/debiasing:** the durable technique is uncertain (CTO weak) → rely on prospective criteria + Objectivity.
- **PE-7:** BA evidence is clinical; non-clinical dating-fatigue transfer unproven.

# FINAL READINESS TEST
**Q1 — Mechanisms with sufficient verified evidence to advance:** construal/perspective shift (M1, reasoning-
level), prospective decision rules / implementation intentions (M6, strongest), evidence discrimination /
belief-updating (M7, as a mechanism), behavioural experiment (M4/M8, conditional). Supporting: self-affirmation
+ self-compassion (buffer); forward-value (M5, reframed). Held/downgraded: values/BA (via M6).

**Q2 — Specific techniques with sufficient verified evidence + contextual fit:** distanced self-reflection;
implementation intentions (if-then with a pre-set criterion); structured evidence-weighing/prospective
criteria; graded behavioural experiment (safety-gated); with forward-value prompt, attribution re-scoping
(global→specific only), and affirmation/compassion as supporting components.

**Q3 — Downgraded/rejected after verification, and why:** *consider-the-opposite* (Hold — weak/mixed real-world
debiasing); *"behavioural experiments outperform verbal methods"* (removed — RCT shows parity); *sunk-cost
education* (reframed — awareness insufficient, no relationship-decision efficacy); *behavioral activation
as-such* (Hold — clinical extrapolation); *attribution re-scoping via controllability* (excluded — self-editing
failure mode); *generic self-esteem / optimism training* (Reject — §21 / optimism guardrail).

**Q4 — Externally demonstrated vs RLC-theory-derived, per advancing technique:** in **every** case the
*technique-level* effect (improved reasoning / goal attainment / belief change / defensiveness reduction) is
**externally supported**, while the *RLC application* (that it improves **dating-fit evaluation and
Exploration→Discernment**) is **RLC-theory-derived / untested directly**. No advancing technique is
Direct-to-target. Phase-2 records therefore ship `Empirically-Supported (technique) / RLC-Theory-Derived
(application)`.

**Q5 — Ready for Phase 2?** **READY** — with the understanding that Phase 2 authors **conditional, bridge-
labeled** interventions (not claims of proven relational efficacy), preserves the active ingredients (Del. 7),
builds in the failure-mode guardrails (Del. 8), and treats dosage/maintenance/transfer as **Provisional**
