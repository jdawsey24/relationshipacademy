## §0. Governing distinction — Barrier ≠ Competency ≠ Change Target
> - **Developmental Barrier** = *what may interfere* (canonical categories: Internal / Relational /
>   Environmental; no named-barrier catalog).
> - **Developmental Competency** = *a developmental capacity* (canonical `kb_competencies`).
> - **Change Target** = *what an intervention attempts to change*.
> **Not interchangeable.** A barrier-category classification does **not** establish that the competency
> architecture contains the capacity a Change Target requires; naming contributing competencies does **not**
> establish complete coverage. Where a target's required capacity is not demonstrably covered by canonical
> competencies, a **Framework Coverage Question (FCQ)** is raised for human adjudication — **never** invent a
> competency or barrier, **never** treat barrier classification as coverage.

## §A. Framework Coverage Question (FCQ) — process + resolution taxonomy (RETAINED, clarified)
FCQs are **retained**. An FCQ may resolve in exactly one of five ways; **only human theoretical review may
reach Resolution E, and no automated process may resolve an FCQ by modifying the framework:**
| Resolution | Meaning |
|---|---|
| **A. Existing Competency Coverage** | the required capacity is adequately represented by an existing canonical competency |
| **B. Task-Supporting Intervention Target** | the target legitimately interferes with developmental functioning but does **not** need to become an RLC competency (see §B) |
| **C. Recognition / Context** | the experience is meaningful but does not require an RLC change intervention |
| **D. Outside RLC Intervention Scope** | the target belongs primarily to another form of support, treatment, assessment, or care |
| **E. Potential Framework-Level Gap** | the framework may genuinely lack a developmental capacity its own architecture requires — **rare; explicit human theoretical review required; no automated framework change** |

## §B. Task-Supporting Intervention Target (NEW — intervention-architecture classification, not RLC theory)
> **Task-Supporting Intervention Target:** a Change Target that is **not itself an RLC Developmental
> Competency**, but whose modification is theoretically and/or empirically justified because the target
> **demonstrably interferes with performance of a canonical Developmental Task, Developmental Competency, or
> Developmental Application.**

**This is an intervention-architecture classification only.** It is **not** a new RLC construct, competency,
domain, developmental task, barrier category, or Experience Cluster, and it is **not** a route to expand the
framework indirectly. Its purpose is to let the intervention system address psychologically-relevant
interference **without forcing every target into the canonical competency architecture** and **without turning
every psychologically-relevant process into a competency.**

**Admissibility — a target is Task-Supporting only if ALL ten hold:**
1. Functional interference is **established or conditionally established** (passes the Change System Gate).
2. The interference affects a **canonical Developmental Task, Competency, or Developmental Application**.
3. The target is **sufficiently specific** to intervention.
4. Altering the target has a **defensible theoretical and/or empirical pathway** to improved developmental
   functioning.
5. The target **cannot be more parsimoniously handled** through an existing canonical competency.
6. The target **does not require redefining** an existing competency beyond its canonical definition.
7. The target is **not** introduced merely because it is psychologically interesting or clinically familiar.
8. The intervention **does not require the target to become part of RLC theory**.
9. Appropriate **context, cultural, safety, and accuracy conditions** can be specified.
10. **Human review confirms** the classification.

**If not all ten hold**, the target must instead be: handled through an existing competency (A) · Recognition/
Context (C) · Held for additional evidence · Referred outside RLC scope (D) · or raised as a genuine
framework-level question (E). A Task-Supporting target must still pass the **Functional Interference Gate,
evidence review, Quality Rubric, Context-Validity rules, suitability routing, and the Portfolio Sufficiency
Test** like any intervention.

## 1. What counts as an RLC Intervention (unchanged)
An intentional, specified change process acting on a defined **Change Target**, through a stated **Change
Mechanism**, in service of improved **Developmental Application**, with specified user action, expected
proximal change, and indications/contraindications/stop/referral. Distinct from education, recognition/
validation, reflection/journaling, a delivery **format** (worksheet/guide/challenge/lesson/video/scenario), a
behavioral suggestion, a Practice, an Enhancement, a clinical technique, and a Play. **Not every worksheet/
exercise/prompt qualifies** (seven necessary conditions).

## 2. Intervention Evidence Chain (updated: Competency **or** Task-Supporting Target at the construct node)
```
Presenting Experience / Problem Expression → Functional Interference (established | conditional; evidence)
  → Developmental Context (Phase→Task) → Change Target
  → Relevant Competency AND/OR Canonical Barrier category AND/OR **Task-Supporting Target**   ⟵ if capacity not covered ⇒ FCQ (resolves A–E)
  → Change Mechanism → Intervention Technique (+ external & RLC evidence labels) → User Action
  → Expected Proximal Change → Developmental Application (BI-mapped) → Expected Developmental Outcome
  → Maintenance / Generalization
```
Governing question: *Why should doing THIS produce change in THIS target for THIS developmental purpose?* No
admission of a target with an **unresolved** FCQ.

## 3. Change-Mechanism requirement (unchanged)
No closed taxonomy. Every intervention states: user action · active process · target affected · why it improves
Developmental Application · observable proximal change. Enforced: **mechanism ≠ technique ≠ format ≠ content ≠
outcome.**

## 4. Evidence-strength labels — DUAL SYSTEM (approved)
**External Technique Evidence:** `Empirically-Supported · Evidence-Informed · Not-Externally-Sourced`.
**RLC Application Evidence:** `RLC-Theory-Derived · RLC-Pilot-Tested · RLC-Empirically-Supported`. *Evidence
for an external technique does not establish empirical support for its RLC application.* Every intervention
states: what is externally supported · what is adapted · what is RLC theory-derived · what is tested within
RLC. Current 333 = `Not-Externally-Sourced / RLC-Theory-Derived`.

## 5. Evidence Hierarchy — Borrow → Adapt → Refine → Invent (approved)
L1 Adopt (empirically-supported technique) · L2 Adapt (evidence-informed, re-anchored) · L3 Refine (existing
RLC asset) · L4 Invent (theory-derived). RLC determines target/purpose; established science used where an
adequate mechanism exists; **invention is last, not default; never modality-first — the technique fits the
target.**

## 6. Recognition/Context vs Intervention; interpretive targets without medicalizing (unchanged)
Recognition/Context is allowed and often essential but **labeled accurately, not inflated** — except where
correcting a knowledge deficit **is** the mechanism. Interpretive/attentional/expectancy/decision/self-
evaluation targets are supported **without assuming pathology** and **without silently creating competencies/
barriers**; where a target exceeds canonical coverage, raise an FCQ (which may resolve to **B. Task-Supporting**).

## 7. Consumer / Professional Suitability (approved)
Suitability is **intervention-specific**, collected at selection/delivery; the **Snapshot is not a clinical
severity screener** (it identifies pattern + developmental context). Routing (person × intervention × context,
**not** mild/moderate/severe):
| **R1 — Self-Guided** | independent consumer use |
| **R2 — Supported / Facilitated** | benefits from facilitation/education/feedback (Academy, workshop, RLC-trained facilitator, coach) — **not inherently clinical** |
| **R3 — Clinician-Dependent** | needs clinical formulation/judgment/treatment skill or management of activation/risk |
| **Excluded / Safety Referral** | not delivered as an RLC intervention in the present context (safety, coercion/abuse, acute destabilization, or a condition needing different care) |
Each intervention records its default routing outcome + the routing information its suitability gate must
collect.

## 8. Safety · Context-Validity · Dosage · Feedback · Practice-vs-Intervention · Real-world transfer · Cultural validity (unchanged)
Indications/context/contraindications/stop/referral specified; Context-Validity Rule enforced (no evidence-
gathering where danger established; no vulnerability where unsafe; **never challenge accurate negative
expectancy**; normal emotion not pathologized; relationship-preservation not assumed). Dosage mechanism-derived
(Provisional where unevidenced); feedback corrective-learning, non-gamified; Enhancements/Practices are
components, not interventions, where interference blocks the capacity; a real-world transfer path bridges to
Developmental Application; cultural assumptions documented, healthy functioning not one norm.

## 9. Success Standard (preserved)
**Success = reduced Functional Interference + stronger Developmental Application** (increased capacity, better
evidence discrimination, behavioral flexibility, appropriate decision-making, maintenance/generalization,
recurrence tolerance). **Never** external-outcome or emotion-elimination.

## 10. Lifecycle + Human review (unchanged)
`Proposed → Theory-Reviewed → Evidence-Reviewed → Usability/Pilot-Ready → Pilot-Tested → Revised →
Validation-Candidate → RLC-Empirically-Supported`; none presented above its validated stage. Mandatory human
adjudication for novel targets/mechanisms, weak mappings, clinical adaptations, safety-sensitive interventions,
professional/clinical routing, **FCQs (including Task-Supporting classification, criterion 10)**, weak evidence,
psychologically-complex targets, cultural assumptions. No automated creation of competency/barrier, stage
elevation, or FCQ resolution.

## 11. Intervention Quality Rubric (unchanged; +FCQ state)
17 dimensions (Strong/Adequate/Weak/Absent/N-A). Dispositions: Admit · Admit-with-Adaptation · Professional-
Only · Hold-for-Evidence · **Hold-for-Adjudication** (unresolved FCQ) · Reject. Any Weak on traceability,
Change-Target, mechanism, or safety blocks Admit.

## 12. Intervention Development Record / Schema (updated fields)
Draft groups retained. **v1.0 fields:** `Target_Type{Competency | Task-Supporting | Recognition-Context}` ·
`Framework_Coverage_Question{status: none|OPEN|resolved, resolution: A|B|C|D|E, note}` ·
`Task_Supporting_Admissibility{criteria 1–10: pass/fail + note}` · `Consumer_Professional_Routing{R1|R2|R3|
Excluded}` · `Required_Routing_Information` · dual evidence labels · `Observed_Interference_Pattern`
(descriptive, non-construct). No framework fields.

## 13. Intervention Portfolio Sufficiency Standard (approved)
Second-level test **after** admission, **before** Playbook translation. Trace: Cluster → Problem Expressions →
Functional Interference pathways → Change Targets → required Change Mechanisms → admitted interventions →
coverage → remaining gaps. Considers major-expression coverage, pathway coverage, mechanism adequacy,
duplication, format-duplicates-of-one-mechanism, appropriate Recognition/Context areas, unresolved FCQs,
routing/safety limits, and whether the portfolio **collectively** gives a credible pathway to reduced
interference + stronger Application. **Not** every statement/expression needs an intervention. Dispositions:
**Sufficient · Sufficient with Recognition/Context Areas · Partially Sufficient · Insufficient** (each with
required trace evidence). A portfolio dominated by format-duplicates of one mechanism cannot be Sufficient.

## 14. Product-Claim Scoping (approved)
> **The scope of a Playbook's promise must not exceed the demonstrated scope of its intervention portfolio.**
Portfolio disposition bounds the claim. Methodological/product-integrity requirement — no consumer copy here.

## 15. Cluster 1 Methodological Stress Test (updated — PE-1 RESOLVED; PE-6 classification check)

**PE-1 — Global self-worth conclusion drawn from relational outcomes — FRAMEWORK COVERAGE QUESTION: RESOLVED**
- **Resolution: B — Task-Supporting Intervention Target.**
- **Ruling:** PE-1 is a legitimate **intervention-level Change Target** whose modification may support
  **Discernment**, but the target is **not** established as an RLC Developmental Competency. **No self-worth
  or self-definition competency is created; no domain expanded; Objectivity/Reflection/Authenticity are not
  redefined to absorb it; no new barrier category; no framework change.**
- **Developmental logic:** relational event/outcome → global self-conclusion → interference with the ability
  to evaluate relational evidence and mutual fit → compromised Discernment.
- **The RLC intervention target is NOT "improve self-worth."** It is: **"reduce the extent to which global
  self-evaluative conclusions drawn from relational outcomes interfere with accurate evaluation of relational
  evidence, mutual fit, and subsequent developmental decision-making."** Destination: **Exploration →
  Discernment.**
- **Constructs:** the **Internal Developmental Barrier** category may describe the *location/type* of
  interference but is **not** the intervention target or a developmental capacity. Objectivity, Reflection,
  Authenticity **may contribute** to Developmental Application where definitionally appropriate but are **not**
  represented as fully containing the target.
- **Admissibility:** meets criteria 1–9 on current analysis; **criterion 10 (human review) = satisfied by this
  adjudication.** PE-1 **may proceed to intervention evidence review under the Task-Supporting pathway**,
  still subject to the Gate, evidence review, Rubric, Context-Validity, routing, and Portfolio Sufficiency.
- **This closes the final hard blocker for Cluster 1 intervention development.**

**PE-6 — Protective Negative Expectancy / Hope–Disappointment Cycle — provisional classification check (no development)**
- **Recommendation: split classification.** The **distorted** subset (pre-discounting/foreclosing evaluation
  despite available evidence) is **provisionally A — Existing Competency Coverage** via **Objectivity**
  ("separates facts from interpretations; evaluates without idealizing or demonizing") and **Curiosity**
  (open exploration) — a stronger competency fit than PE-1 had. **Task-Supporting (B) is a fallback** only if
  evidence review shows exercising Objectivity/Curiosity is insufficient to move the distorted-expectancy
  target. The **accurate-expectancy** subset (expectations supported by repeated observable relational
  behavior) is **C — Recognition/Context / validation** and is **out of intervention scope**.
- **Non-negotiable guardrail (Context-Validity §8):** protective negative expectancy is intervention-relevant
  **only** when it distorts or prematurely forecloses evaluation. **Accurate negative expectations must never
  be challenged simply because they are negative. The intervention system must never teach optimism over
  evidence.**
- **No theoretical contradiction found** — PE-6 does **not** block the freeze; final classification resolves
  during PE-6 evidence review.

**PE-8 — loneliness/longing:** unchanged — **Recognition/Context only**; no intervention unless Functional
Interference is independently established (non-pathologizing test passed).
**PE-2/PE-3/PE-4/PE-5/PE-7:** unchanged from v1.1 (competency-anchored or, for PE-4, Reciprocity with the
information-not-scorekeeping guardrail; none raised an FCQ).
